# mindmap

n8n 스타일의 무한 캔버스 마인드맵 웹앱입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 실행

```bash
# 파일을 바로 열거나
open index.html
# 간단한 로컬 서버로 실행
python3 -m http.server 8000   # http://localhost:8000
```

## 기능

- **무한 캔버스**: Space+드래그 또는 오른쪽/가운데 버튼 드래그로 화면 이동(터치는 한 손가락), 마우스 휠로 확대/축소, `전체 보기`로 모든 도형에 맞춤
- **여러 도형 선택·이동**: 빈 곳을 드래그하면 사각형 범위 안의 도형이 모두 선택되고, 선택된 도형 중 하나를 끌면 함께 이동. Shift/Ctrl+클릭으로 선택 추가·해제, Ctrl+A 전체 선택. 여러 개 선택 시 속성 패널의 스타일·포트 변경과 삭제도 한 번에 적용
- **도형 추가**: 사각형 · 원 · 마름모 · 텍스트 (툴바 버튼 또는 빈 곳 더블클릭 시 사각형)
- **이름 변경**: 도형 더블클릭(또는 선택 후 Enter) → 입력 → Enter로 확정, Esc로 취소 / 오른쪽 속성 패널에서도 수정 가능
- **화살표 연결**: 도형 양옆의 점(●)을 드래그해서 다른 도형의 점(또는 도형 위)에 놓으면 화살표로 연결. 선은 모서리가 둥근 직각(ㄱ자) 형태로 자동 배치되고, 뒤로 돌아가는 연결은 다른 도형을 피해 우회
- **글자 스타일**: Pretendard 글꼴(저장소에 포함, 오프라인 동작), 굵기 100~900, 크기 8~120px, 글자색
- **도형 스타일**: 채우기 색(투명 포함), 외곽선 색, 외곽선 굵기 0~12px. 텍스트에도 테두리 적용 가능. 팔레트 외 색은 🌈 버튼으로 직접 선택
- **포트 개수 조절**: 도형을 선택하면 아래쪽에 `− N +` 컨트롤이 나타남. 왼쪽/오른쪽 각각 0~12개까지 추가·삭제 가능 (속성 패널에서도 가능)
- 도형 이동, 오른쪽 아래 핸들로 크기 조절, 모양 변경
- 선택 후 Delete/Backspace로 도형·화살표 삭제
- 실행 취소/다시 실행 (Ctrl+Z / Ctrl+Shift+Z)
- 브라우저(localStorage)에 자동 저장, JSON 내보내기/불러오기
