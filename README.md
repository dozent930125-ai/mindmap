# mindmap

n8n 스타일의 무한 캔버스 마인드맵 웹앱입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## claude.ai에서 쓰기 (공유 · 공동 편집 · Claude 채팅)

같은 코드를 claude.ai 아티팩트로 올리면 다음 기능이 켜집니다.

- **실시간 공유 저장**: 마인드맵이 아티팩트의 공유 DB(`nodes/<id>`, `edges/<id>` 문서)에 저장되고, 같은 링크를 연 사람들끼리 수정 내용이 실시간으로 반영됩니다. 화면 위치(이동/확대)는 사람마다 따로 기억합니다.
- **권한**: 공유 메뉴에서 보기 권한만 받은 사람은 `보기 전용`으로 열립니다(도형 추가·수정·삭제 불가, 이동/확대/선택/내보내기/채팅은 가능).
- **Claude와 대화**: 오른쪽 위 `Claude와 대화` 버튼. 각자 자기 Claude 계정 사용량으로 동작합니다.
  - 모델: `빠른 모델` / `기본 모델` / `최고 성능 모델` 중 선택 (요금제에 따라 가능한 단계로 대체될 수 있음)
  - `그냥 대화`: 마인드맵과 무관한 자유 대화
  - `마인드맵 함께 편집`: Claude가 현재 도형·연결·선택 상태를 읽고, 요청하면 도형·텍스트·화살표를 직접 추가/수정/삭제하고 자동 정렬(간격 조절)합니다. 한 번의 요청으로 바뀐 내용은 채팅의 `되돌리기` 또는 Ctrl+Z 한 번으로 되돌릴 수 있습니다. 보기 전용 사용자는 읽기만 가능합니다.

배포용 페이지는 `python3 tools/build_artifact.py`로 `dist/mindmap.html`을 만든 뒤, `styles.css`, `app.js`, `chat.js`, `fonts/`와 함께 `db`, `sample`, `user`, `downloads` 기능을 선언해 게시합니다.

파일로 직접 열면(아래 실행 방법) 기존처럼 이 브라우저에만 저장되고 채팅 버튼은 보이지 않습니다.

## 실행

```bash
# 파일을 바로 열거나
open index.html
# 간단한 로컬 서버로 실행
python3 -m http.server 8000   # http://localhost:8000
```

## 기능

- **무한 캔버스**: 빈 곳을 왼쪽 드래그하면 화면 이동(클릭은 선택 해제, Space+드래그·가운데 버튼도 가능), 마우스 휠로 확대/축소, `전체 보기`로 모든 도형에 맞춤, `전체 화면` 버튼
- **여러 도형 선택·이동**: 오른쪽 버튼으로 드래그하면 사각형 범위 안의 도형이 모두 선택되고, 선택된 도형 중 하나를 끌면 함께 이동. Shift/Ctrl+클릭으로 선택 추가·해제, Ctrl+A 전체 선택. 여러 개 선택 시 속성 패널의 스타일·포트 변경과 삭제도 한 번에 적용
- **도형 추가**: 사각형 · 원 · 마름모 · 텍스트 (툴바 버튼 또는 빈 곳 더블클릭 시 사각형)
- **이름 변경**: 도형 더블클릭(또는 선택 후 Enter) → 입력 → Enter로 확정, Esc로 취소 / 오른쪽 속성 패널에서도 수정 가능
- **화살표 연결**: 도형 양옆의 점(●)을 드래그해서 다른 도형의 점(또는 도형 위)에 놓으면 화살표로 연결. 선은 모서리가 둥근 직각(ㄱ자) 형태로 자동 배치되고, 뒤로 돌아가는 연결은 다른 도형을 피해 우회
- **글자 스타일**: Pretendard 글꼴(저장소에 포함, 오프라인 동작), 굵기 100~900, 크기 8~120px, 글자색
- **도형 스타일**: 채우기 색(투명 포함), 외곽선 색, 외곽선 굵기 0~12px. 텍스트에도 테두리 적용 가능. 팔레트 외 색은 🌈 버튼으로 직접 선택
- **포트 개수 조절**: 도형을 선택하면 아래쪽에 `− N +` 컨트롤이 나타남. 왼쪽/오른쪽 각각 0~12개까지 추가·삭제 가능 (속성 패널에서도 가능)
- 도형 이동, 오른쪽 아래 핸들로 크기 조절, 모양 변경
- 선택 후 Delete/Backspace로 도형·화살표 삭제
- **복사/붙여넣기**: Ctrl+C / Ctrl+V (여러 개 선택 시 사이의 화살표도 함께 복사), Ctrl+X 잘라내기, Ctrl+D 복제. 붙여넣을 때마다 조금씩 옆으로 밀려서 놓임
- 실행 취소/다시 실행 (Ctrl+Z / Ctrl+Shift+Z)
- 브라우저(localStorage)에 자동 저장, JSON 내보내기/불러오기
